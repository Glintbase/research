2. Execute a Python script inside the sandbox that calculates and prints:
import polars as pl
print(f"SUM:{pl.Series([10, 20, 30]).sum()}")
3. Print the output (must contain 'SUM:60').
4. Cleanly terminate the sandbox using sb.terminate() in a finally block.
